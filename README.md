# Budget Tracker

A full-stack budget and expense tracking web application built with Django as my capstone project for the Full Stack Development Immersive program at San Diego Global Knowledge University.

The application allows users to create and manage budgets, track expenses, and monitor how much money remains available.

## Features

- Create and manage multiple budgets
- Add and track expenses
- Calculate remaining budget balances
- User account functionality
- Persistent data storage with SQLite
- Responsive web interface
- Form handling and validation

## Built With

- Python
- Django
- SQLite
- HTML
- CSS
- JavaScript
- Bootstrap
- Django Crispy Forms

## Project Structure

The project is organized into separate Django applications for budget functionality and user-related features, with dedicated templates, static assets, and configuration files.

## About the Project

Budget Tracker was developed as the capstone project for my Full Stack Development Immersive program. It gave me hands-on experience connecting front-end interfaces, server-side application logic, user-facing forms, and persistent database storage within a complete Django application.
